Before you start

LinkUnzip works without these. You can change them any time in Settings.

Site access

LinkUnzip asks the first time you use a link on a new site. Allow every site to skip that question. It still only connects to a site when you give it a link there.

Where extracted files go

For zips with thousands of files, a folder you choose is much faster. {browser} doesn't let extensions use Downloads, Desktop or Documents themselves, so pick a folder inside one of them.

The Windows helper

LinkUnzip doesn't need it. Once it is installed, Settings > Extract with the Windows helper lets it save straight into Downloads, which is faster for zips with thousands of files, and Open folder opens Explorer there. It also brings the linkunzip command line.
