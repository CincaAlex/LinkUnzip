How it works

Three steps, no ZIP left behind

A ZIP keeps its table of contents at the end of the file. LinkUnzip reads that part first, so it knows every file, its size and where it sits in the zip before a single byte is written.

  1. Right-click a .zip link

    Choose Extract with LinkUnzip. Or click the toolbar icon and paste a link: it also lists the .zip links on the page you are on.

  2. See the cost, pick what you want

    The files, their sizes, the space a normal download would need and the space you have. Tick only the files you want and choose a folder with Browse...

  3. Files land in the folder

    Only the needed parts of the zip, over several connections. Each file gets its real name only after its CRC-32 and size check out. Then Open folder.

The first time: add the extension, then the setup page that opens installs the free LinkUnzip helper for Windows. Two clicks, just for you, no administrator rights. Why a helper?

Under the hood

LinkUnzip first asks the server for just the end of the file (HTTP Range requests), finds the zip's central directory (ZIP64 included), and plans which byte ranges hold the files you chose. Neighbouring files are fetched together in one request per span, several spans at a time (4 connections by default, 1 to 16). Each file is inflated as it arrives, written as .part, checked against the CRC-32 and size in the index, then renamed. Servers that cannot send part of a file, like GitHub's Download ZIP, are read once from start to end instead: one connection, no preview, still no ZIP on disk.

FAQ

Questions

Why does it need a helper program?

A browser extension can't write a folder full of files wherever you choose, and can't stream gigabytes to disk efficiently. The LinkUnzip helper is a small Windows program that does the downloading and unpacking.

It installs just for you, without administrator rights, and only runs while you use LinkUnzip: it closes about 30 seconds after the last job. It talks only to the extension and to the server of the link you chose.

Why Windows only?

The helper is built and tested on Windows so far. macOS and Linux helpers, and a Firefox version, are on the list, with no date yet.

Windows says it doesn't recognise the installer

New programs have to build a reputation with Microsoft Defender SmartScreen, and an installer without a code signature shows "Windows protected your PC". Click More info, then Run anyway.

You can check the file against SHA256SUMS.txt on the release page, and read the source code on GitHub.

Does it work with private links? Is reading my cookies safe?

Public links need no permission at all. If a download needs your login, LinkUnzip says so and offers Use my login on <site>; your browser then asks you once for that one site.

Only after that does the extension read that site's cookies, and only for the zip you chose. They go to the helper on your PC, which sends them only to that same site. Nothing is sent to the developer: there is no LinkUnzip server. Details in the privacy policy.

What doesn't it do?
  • RAR and 7z, and creating archives.
  • Password-protected zips (planned) and rare compression methods such as Deflate64, bzip2 or LZMA.
  • Downloads that only exist inside a web page (blob: links, as in some web apps).
  • Links that need a form POST or a one-time token.
  • Saving disk space for the files themselves: the extracted files still need their room. LinkUnzip saves you the room the ZIP would take.

When a link can't be read this way, Download normally hands it back to the browser.

What if the connection drops?

The file being written starts again from its beginning; files already finished stay in the folder. If you stop a job, or it fails, Resume picks it up and skips every file that is already there and verified.

In one-pass mode (GitHub's Download ZIP and other servers that can't send parts of a file), a dropped connection starts the pass again from the beginning of the zip, skipping files already done.

Is it safe to extract archives from strangers?

LinkUnzip treats every archive as untrusted. It refuses path tricks (.., absolute paths, drive letters), renames names Windows can't store and tells you, never writes more than a file's declared size, and stops before the disk fills up. It says which files it can't extract instead of skipping them silently.

How do I remove it?

Remove the extension from the browser, then open Windows Settings › Apps › Installed apps › LinkUnzip › Uninstall. That removes the helper and its browser registration.

Does it cost anything?

No. No account, no ads, no tracking, and this website has no cookies or trackers either.
