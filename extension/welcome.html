LinkUnzip

Extract a ZIP straight from a link into a folder, without ever saving the ZIP.

  1. Add the extension

    Done. Everything runs here in the browser: there is nothing else to install.

  2. Let LinkUnzip read zip links

    To read a zip's index and only the files you pick, LinkUnzip asks the zip's server for parts of the file. Chrome needs your permission for that. LinkUnzip only connects to a site when you give it a link there, and nothing goes anywhere else.

    Prefer to decide per site? Skip this: LinkUnzip asks the first time you use a link on a new site.

  3. Where extracted files go

    Into your Downloads folder, in a folder named after the zip. Nothing to set up.

    Zips with thousands of files are much faster into a folder you choose: Chrome's downloads save about 6 files a second. Chrome doesn't let extensions pick Downloads, Desktop or Documents themselves, so make a folder inside one of them (for example Downloads > LinkUnzip) and pick that.

  4. Try it

    Right-click any link to a .zip file and choose Extract with LinkUnzip. Or click the LinkUnzip icon in the toolbar and paste a link.

    Can't see the icon? Click the puzzle piece next to the address bar, then the pin next to LinkUnzip.

    Optional: the LinkUnzip helper for Windows

    A few servers (like GitHub's green "Download ZIP" button) can only send a zip from the start. The browser version can't read those yet; the helper program for Windows can, in one pass. It also brings the linkunzip command line. Get it on GitHub.
